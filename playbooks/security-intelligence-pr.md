# Security Intelligence PR Playbook

- Distinguish source claim, observed evidence, analysis and inference.
- Do not overstate compromise, exploitation, attribution or customer impact.
- Prefer primary sources for vulnerability and vendor facts.
- Include timestamps and evidence status when recency matters.
- Use responsible disclosure boundaries for sensitive vulnerabilities.
- Promote analyst value: context, prioritization, defensive action and provenance.
- Avoid fear-only headlines that reduce long-term credibility.
