# Publication & Brand Governance

## Mandatory quality gates

A campaign cannot be approved until all gates pass:

| Gate | Requirement |
|---|---|
| Accuracy | Every factual claim is supported by a current source or product evidence. |
| Security | No secret, credential, exploit-sensitive detail, customer data or internal-only material is exposed. |
| Brand | CYBERDUDEBIVASH® spelling, platform names, tone and canonical URLs are correct. |
| Legal / reputation | No fabricated endorsement, customer, certification, partnership or attribution. |
| Audience | Message addresses a defined buyer/practitioner segment and a concrete need. |
| Commercial | CTA maps to an owned destination and measurable outcome. |
| Measurement | Campaign has KPIs and a post-campaign review date. |

## Approval classes

- **Class A — routine:** evergreen platform awareness, education, documented product capability.
- **Class B — elevated:** security intelligence, vulnerability coverage, competitive claims, customer references.
- **Class C — critical:** incident response, breach claims, legal/regulatory positioning, crisis communications.

Class B and C content requires explicit human approval before external distribution.
