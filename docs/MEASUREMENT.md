# Measurement Framework

## North-star outcome

**Qualified ecosystem demand:** meaningful visits, product exploration, trials/inquiries, enterprise conversations, toolkit purchase intent, academy enrollment intent, API adoption intent and repeat engagement.

Raw reach is diagnostic. It is not the north-star outcome.

## Attribution contract

Every governed campaign should have:

- one deterministic campaign ID;
- one canonical destination;
- channel-specific UTM URLs;
- one primary business objective;
- a defined measurement window;
- aggregate performance records where data is available.

`utm_campaign` must equal the campaign ID.

## KPI hierarchy

### Awareness
- qualified impressions;
- branded search growth where a validated source exists;
- earned mentions and citations;
- share of relevant technical conversations.

### Engagement
- click-through rate;
- engaged visits;
- report/tool/course depth where first-party telemetry exists;
- repeat engagement;
- content saves/shares by target audiences.

### Commercial intent
- contact/enterprise CTA actions;
- demo or assessment inquiries;
- API/toolkit interest;
- academy enrollment intent;
- qualified lead creation.

### Ecosystem expansion
- cross-platform navigation rate;
- percentage of aggregate sessions touching two or more ecosystem products where privacy-safe measurement exists;
- conversion assisted by another CYBERDUDEBIVASH® property.

## Core funnel equations

- `CTR = clicks / impressions`
- `Engaged visit rate = engaged visits / clicks`
- `CTA rate = CTA actions / engaged visits`
- `Lead rate = leads / engaged visits`
- `Conversion rate = conversions / clicks`

Zero denominators produce a zero rate and must not be interpreted as evidence of performance.

## Performance index

The Growth Attribution Engine calculates a bounded 0–100 target-attainment index using policy-controlled KPI targets and weights.

This index is:

- an internal prioritization signal;
- not an external benchmark;
- not proof of causality;
- not a market-leadership claim.

## Privacy and publication rules

The public repository must not become an analytics warehouse.

Public repository performance files must contain aggregate, publication-approved metrics only.

Customer-private, person-level or commercially sensitive data must be processed in a private runtime or private data store.

## Measurement rule

Do not optimize campaigns exclusively for raw impressions. Prefer qualified engagement, authority, referral quality, product exploration and commercial movement.

Do not make a causal claim when the evidence only supports attribution or correlation.
